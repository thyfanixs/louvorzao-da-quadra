# Louvorzão da Quadra

Evento evangelístico anual de louvor e adoração na quadra do bairro Barbosa, em Capim Branco/MG.

- **Próxima edição:** sábado, 10/04/2027
- **Tema 2027:** Praticantes da Palavra (Tiago 1:22, ACR)
- **Entrada:** gratuita

## Estrutura

```
divulgacao/
  2027-carrossel-era/      Carrossel "Fim da Era 2026 → Era 2027" (Instagram 4:5)
    canvas/                Arquivos das artes (canvas.json + 5 cards .dc.html)
    assets/                Fotos tratadas, recortes, texturas e logo
    legendas.md            Legendas do post
```
